# IInkPilot

This repository stores the InkPilot V0.1 reference materials and the first-pass implementation planning notes.

## Included

- `InkPilot_V0.1_Codex_Master_Prompt.md`
- `docs/implementation-plan.md`

## Current Status

This repository is currently in planning/bootstrap stage.

The current recommended first development pass is:

1. Bootstrap a new iPadOS SwiftUI app.
2. Build the InkPilot home screen and canvas shell.
3. Add PencilKit drawing.
4. Add mock AI ghost suggestion flow.
5. Prepare English and Simplified Chinese localization.
6. Add baseline accessibility labels for core controls.
