## 3. Undo/Redo Fixes

| Issue | Fix |
|---|---|
| Drag didn't push history | Added `onDragStart` callback → `pushHistoryBeforeMove()` |
| Resize didn't push history | Added `onResizeStart` callback → `pushHistoryBeforeResize()` |
| History pushed once per gesture | ✅ Push on first frame only, not every onChanged |

**Supported undo/redo actions:**
- ✅ Object add
- ✅ Object move (push at drag start)
- ✅ Object resize (push at resize start)
- ✅ Object delete
- ✅ Object duplicate
- ✅ Bring forward / send backward
- ✅ Clear canvas
- ✅ New action clears redo stack
- ✅ Max 30 history entries

**Not supported:**
- Drawing undo/redo (PencilKit manages its own drawing undo internally)

## 4. Persistence Fixes

| Issue | Fix |
|---|---|
| Corrupted file crashes | Added try/catch with Logger warning |
| Corrupted file retried on next launch | Corrupted file deleted after decode failure |
| PKDrawing encoding | Uses `dataRepresentation()` (safe) |
| PKDrawing decoding | Uses `PKDrawing(data:)` with fallback to empty |
| Auto-save debounced | ✅ 0.5s debounce |

**Persistence format:**
- `CanvasDocument` (Codable)
- `drawingData: Data` (PKDrawing binary)
- `canvasObjects: [CanvasObject]` (Codable)
- `createdAt`, `updatedAt`, `appVersion`
- Saved as JSON to `Documents/inkpilot_canvas.json`
