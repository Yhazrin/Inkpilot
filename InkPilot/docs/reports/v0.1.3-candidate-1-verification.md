6. **Connector + mind-map interaction not exercised in screenshots** — `07-seeded-objects.png` shows shape/text/sticky; connector was not seeded. Manual device run needed.
7. **No "selected" border on `MarqueeMarqueeLayer` after clear** — selecting via marquee then tapping empty canvas should clear selection; `CanvasView` line 73-80 implements this but the `onTapGesture` in select mode + hasSelection might shadow the marquee gesture. Static screenshots can't validate the conflict.
