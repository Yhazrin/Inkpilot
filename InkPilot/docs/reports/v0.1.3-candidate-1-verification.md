## P0 — Must fix before tag

1. **`acceptSuggestion()` type dispatch** — `CanvasViewModel+AI.acceptSuggestion()` is the line B P0 (your original ask). Real AI returning `textBox / stickyNote / connector / shape` must not all collapse to `aiCard`. *This is the highest-value fix in the patch set.*
2. **`PenSettingsPalette` auto-expand on pen selection** — `feedback_collapsed_chrome`: when user picks the pen tool, palette shows full pen-type + 4 widths + 7 colors immediately. Clutter confirmed in `02-tool-select.png` and every other non-text/non-shape-non-media shot. Default to a single indicator (color dot + width), tap to expand. Tracked as Task #56.

## P1 — Should fix

3. **`textBox(title:body:)` factory drops `title`** — `CanvasObjectFactory.swift:39-45` only stores `body` (or `title` if body is empty). `07-seeded-objects.png` shows "World" only. Either rename parameter or merge into a single field.
4. **PenSettingsPalette has no "selected" affordance in chrome** — palette always shows even when no pen is selected, since the toggle is `viewModel.selectedTool == .pen && viewModel.drawingToolState.isDrawingTool`. After fix #2, the same condition is fine.

## P2 — Nice to have

5. **Empty-canvas export produces a near-empty image** — `exportToShareURL(screenSize:)` uses `UIScreen.main.bounds.size` which renders to ~1032×1366 white surface for a fresh canvas. JPEG was 115 KB even with 4 seeded objects. Consider trimming to the union of ink bounds + object bounds.
6. **Connector + mind-map interaction not exercised in screenshots** — `07-seeded-objects.png` shows shape/text/sticky; connector was not seeded. Manual device run needed.
7. **No "selected" border on `MarqueeMarqueeLayer` after clear** — selecting via marquee then tapping empty canvas should clear selection; `CanvasView` line 73-80 implements this but the `onTapGesture` in select mode + hasSelection might shadow the marquee gesture. Static screenshots can't validate the conflict.
